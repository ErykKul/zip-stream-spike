    What does this check test?
    
This page runs the ZIP download engine from the Dataverse frontend. It creates test data locally, feeds it through the same range-reading, checksum, ZIP creation, and browser-saving code, then checks the ZIP you saved.

    
No dataset or login is needed, and nothing is uploaded. A pass applies to the browser and machine you tested. It does not test a Dataverse installation’s network, permissions, or storage configuration.

    
Keep this tab open and your computer awake during the check. If asked where to save the download, choose a folder on disk. The page cannot read your Downloads folder automatically, so it asks you to choose the finished file before reporting a verified result.

    
A small ZIP checks the setup. Each RAM button first checks that the page can stop a waiting source, then exercises recovery from simulated response failures and an archive larger than your stated memory. The source stays open for at least 12 minutes, including a deliberate quiet interval. The saved ZIP verifies resumed bytes, ZIP64 structure, and every entry’s checksum.

    
You can use another tab while the test runs; visibility changes are recorded. Native download-manager cancellation, reload warning dialogs, sleep/wake, and a real network disconnection need separate tests. This page does not pretend to perform those browser or operating-system actions automatically.
