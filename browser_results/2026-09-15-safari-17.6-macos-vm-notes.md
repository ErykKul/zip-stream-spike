# Safari VM environment and memory observation

Tester: Eryk. These details were supplied after the
[verified 35 GiB report](2026-09-15-safari-17.6-macos-vm-35gib.json).
The raw JSON remains unchanged, including its `ramGiB: 32` button selection and
`memoryObservation: "not-measured"`. This note records the subsequent clarification.

## Environment

- macOS Sonoma **14.8.9**, x86_64; **Safari 17.6**.
- QEMU/KVM VM via Docker-OSX, image tag `sickcodes/docker-osx:latest`,
  **QEMU 10.1.2**, on an **Arch Linux** host.
- **16 GB RAM assigned**; Activity Monitor showed **15.63 GB Physical Memory**.
- **8 vCPUs**, CPU model `Haswell-noTSX`, SMBIOS `iMacPro1,1`.
- **No GPU acceleration**.

The 32 GB test button selected a 35 GiB payload; it does not describe the VM's
actual RAM. The saved and verified archive exceeded twice the assigned VM RAM.
This is a Safari/macOS VM result, not a host-memory measurement or a run by Julian.
